# Muurahaispeli

Pelin ideana on saada kasvatettua tietty määrä muurahaisia tietyssä ajassa.
Pelaajan tulee ostamaaan tavaroita kaupasta ja kasvattaa kasveja, näiden avulla voidaan nostaa kuinka paljon muurahaisia lisääntyy päivän aikana.

Asiat jotka vielä puuttuvat ohjelmasta:
- tallennus ei toimi täydellisesti, tallentaa vain päivän, nimen ja muurahaisten määrän.
- Kasvien istuttaminen on alku vaiheessa vielä, en ole valmis tämän kanssa.
- Kaupan tavarat pitäisi randomisoitua joka päivä.
- Kohteen vaihtaminen pitäisi kestää noin 1h, jonka jälkeen kun menet kotiin ja käytät kyseisen tavaran, tämä laskee multiplier esimerkiksi 21/24 * (growthrate + boost) + 3 x growthrate
- Kaupan tavaroita pitäisi ostaa muurahaisilla
